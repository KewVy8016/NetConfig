# เอกสารโครงการ NetConfig

เริ่มต้นที่ `../AGENTS.md` ซึ่งเป็นคู่มือบังคับสำหรับเอเจนต์ เอกสารในโฟลเดอร์นี้เป็น
รายละเอียดประกอบที่ต้องอ่านตามลำดับที่คู่มือกำหนด.

- `RULE.md` — กฎด้าน security, quality, testing และการเปลี่ยน configuration
- `DECISIONS.md` — architectural decisions และประเด็นที่ยังต้องตัดสินใจ
- `CONFIG_COVERAGE.md` — scope, gap analysis และ acceptance matrix
- `TASKS.md` — แผนงานกลางแบบ checklist และ checkpoint ของแต่ละ phase

เอกสารสำหรับทำความเข้าใจและใช้งานแอป:

- [FEATURES.md](FEATURES.md) — ฟีเจอร์ จุดเด่น ขอบเขต และสถานะที่ทำแล้ว/ยังรอตรวจ
- [ARCHITECTURE.md](ARCHITECTURE.md) — โครงสร้างไฟล์และ workflow ของข้อมูลตั้งแต่ UI ถึงอุปกรณ์
- [USER_GUIDE.md](USER_GUIDE.md) — วิธีเปิดแอป เพิ่ม Node ตั้งค่า และตรวจผล/แก้ปัญหาเบื้องต้น
