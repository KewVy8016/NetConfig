Save Configuration?

This will run write memory on R1, saving the running configuration to startup configuration. This is a non-destructive operation.

Remove RIP Configuration?

This will remove all RIP settings from R1. The following commands will be generated:

no router rip

RIP routes will be removed from the routing table.

Remove OSPF Configuration?

This will remove all OSPF settings from R1. The following commands will be generated:

no router ospf 1

OSPF neighbor adjacencies will be torn down. Routes will be removed.

Remove EIGRP?

This will disable EIGRP process AS 100 on this device. All EIGRP routes will be removed from the routing table.

Remove BGP?

This will disable BGP process AS 65001 on this device. All BGP peer sessions and routes will be terminated.
